## 🚀 Projeto em destaque

### Central de Atendimento de T.I
Sistema de chamados criado do zero, dentro do próprio Google Workspace, sem servidor e sem custo de infraestrutura.

| | |
|---|---|
| 📝 **Abertura de chamado** | Formulário validado, com campos obrigatórios e anexo opcional (PNG, JPG, PDF, DOC e DOCX) |
| 🔖 **Protocolo automático** | Cada chamado recebe um número único, registrado em planilha |
| 📎 **Anexos no Drive** | Arquivos salvos automaticamente, com link junto ao chamado |
| ✉️ **E-mail de confirmação** | Quem abre recebe o protocolo e a T.I recebe uma cópia |
| 🔒 **Confiabilidade** | Trava contra envio duplicado, validação no servidor e tratamento de erros |
| 🎮 **Minijogo** | Depois do protocolo, um jogo estilo dinossauro do Chrome com o técnico Lucas, feito em Canvas puro |

**Stack:** HTML · CSS · JavaScript · Google Apps Script · Google Sheets · Google Drive · Google Sites
