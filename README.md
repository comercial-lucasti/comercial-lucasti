## 👋 Sobre mim

Sou **analista de T.I** e resolvo problemas de operação com **tecnologia, automação e inteligência artificial**.
Minha especialidade é pegar processos manuais, lentos ou espalhados e transformá-los em **fluxos automáticos, integrados e mensuráveis**.

- 🤖 **Especialista em I.A:** aplico inteligência artificial para ganhar tempo, reduzir erros e apoiar decisões
- ⚙️ **Automação de tarefas:** elimino trabalho repetitivo e conecto sistemas, planilhas, e-mails e rotinas do dia a dia
- 🏢 **Implantação de ERPs e CRMs:** experiência em diversos ERPs e CRMs (Olist, Bling, Odoo, Omie, RD Station e outros), do levantamento de requisitos ao funcionamento na operação
- 🧩 **Solução de problemas:** diagnóstico, priorização e resolução, com foco no impacto real para o negócio
- 🛠️ **Suporte e infraestrutura:** atendimento estruturado, com protocolo, histórico e prioridade

## 🚀 Projetos em destaque

### [EComHub](https://github.com/comercial-lucasti/ecomhub)
Plataforma de operação para e-commerce que reúne **etiquetas, expedição, margem, estoque, reposição e IA** num único painel, no lugar de várias ferramentas pagas.

| | |
|---|---|
| 🏷️ **Etiquetas e expedição** | Etiquetas de marketplaces prontas para imprimir e conferência de saída com histórico |
| 💰 **Margem e custos** | Margem real por canal, com taxas configuráveis e ficha de custo por produto |
| 📦 **Estoque e reposição** | Lê o ERP e sugere quanto comprar, com curva ABC e alerta de pedidos perto de atrasar |
| 🤖 **Assistente de IA** | Rascunhos de anúncios e respostas, com remoção de dados pessoais antes de qualquer envio |
| 🔒 **Segurança e qualidade** | Login com sessão única, dados de clientes só no navegador e mais de 500 verificações automatizadas |

**Stack:** Google Apps Script · JavaScript · Python · APIs REST (OAuth 2) · LLMs  
**Repositório de apresentação:** [github.com/comercial-lucasti/ecomhub](https://github.com/comercial-lucasti/ecomhub) (código privado, todos os direitos reservados)

### [Central de Atendimento de T.I](https://github.com/comercial-lucasti/central-atendimento-ti)
Sistema de chamados criado do zero para organizar o suporte de uma operação real: sem servidor, sem custo de infraestrutura e com tudo rastreável.

| | |
|---|---|
| 📝 **Abertura de chamado** | Formulário validado, com campos obrigatórios e anexo opcional (PNG, JPG, PDF, DOC e DOCX) |
| 🔖 **Protocolo automático** | Cada chamado recebe um número único, registrado em planilha |
| 📎 **Anexos organizados** | Arquivos salvos automaticamente, com link junto ao chamado |
| ✉️ **E-mail de confirmação** | Quem abre recebe o protocolo e a T.I recebe uma cópia |
| 🔒 **Confiabilidade** | Trava contra envio duplicado, validação no servidor e tratamento de erros |
| 🎮 **Minijogo** | Depois do protocolo, um jogo estilo dinossauro do Chrome com o técnico Lucas, feito em Canvas puro |

**Stack:** HTML · CSS · JavaScript · Google Workspace  
**Repositório (código visível, todos os direitos reservados):** [github.com/comercial-lucasti/central-atendimento-ti](https://github.com/comercial-lucasti/central-atendimento-ti)

### [Controle de Ponto](https://github.com/comercial-lucasti/controle-de-ponto)
Registro de ponto por botões, com resumo diário para o gestor e **Diário de Bordo em PDF** gerado automaticamente.

| | |
|---|---|
| 🕒 **Registro de ponto** | Quatro ações (entrada, almoço, retorno e saída) gravadas em planilha, sem duplicidade |
| ✉️ **Comprovante e resumo** | O colaborador recebe o comprovante e o gestor recebe um resumo por dia, com a jornada calculada |
| 📄 **Diário de Bordo** | Notebook no Google Colab lê a planilha e gera o PDF do período, pronto para assinar |
| 🔒 **Privacidade** | Nenhum dado pessoal no código, configuração por propriedades do script |

**Stack:** Google Apps Script · Google Sheets · Python · Google Colab · Pandas · ReportLab  
**Repositório (código visível, todos os direitos reservados):** [github.com/comercial-lucasti/controle-de-ponto](https://github.com/comercial-lucasti/controle-de-ponto)

## 🧭 Como eu trabalho

- **Entender antes de construir:** começo pelo problema do negócio, não pela ferramenta
- **Simples primeiro:** a solução mais enxuta que resolve e dá pouca manutenção
- **Automatizar o que se repete:** se é manual e acontece toda semana, vira rotina automática
- **Testar de ponta a ponta:** do clique do usuário até o resultado final
